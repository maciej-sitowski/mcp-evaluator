# Getting started with Product One

Product One is a note-taking app for teams.

## Create an account

Sign up with your work email. You will receive a verification link that is valid for 24 hours.

## Create your first note

Press N or click New note. Notes are saved automatically every 5 seconds.

## Keyboard shortcuts

Use Ctrl+K to search all notes, Ctrl+Shift+P to open the command palette and Ctrl+/ to list every shortcut.
